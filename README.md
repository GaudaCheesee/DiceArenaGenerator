Собственно, позволяет легче создавать персонажей для моей настольной игры "Dice Arena: Duel". 
Игра фанатская, не официальная. Код был написан с помощью нейросети Claude.
Генератор позволяет писать текст, выбирать характеристики способностям, вставлять картинки для персонажа и каждой способности.
Экспорт в 2 вариантах: архив со всеми карточками или 1 пнг со всеми картами персонажа. Так же доступен экспорт в json для последующего импорта обратно в генератор.
